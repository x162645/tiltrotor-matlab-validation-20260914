## CSV 解释

- `table_name`、`pdf_page`、`printed_page`：原表和原始页位置。
- `alpha_deg`：平尾攻角 α_H，单位度；`elevator_deg`：升降舵角 δ_e，单位度。
- `mach_label`：原表马赫数列标签。`0-0.2` 表示同一低马赫区间，不是多个独立马赫采样点。
- `quantity`、`value`、`unit`：原表量、数字及单位。这些系数均无量纲。
- `status=CONFIRMED_VISUAL`：原始扫描页上可清晰读出的数字。
- `status=NOT_DEFINED`：原表合并的 Not Defined 区域按该表已有攻角/马赫网格展开标记，`value` 留空，未改成零。
- `status=REFERENCE_TABLE_5_I`：原表要求使用 Table 5-I；`value` 留空，没有复制或计算被引用数值。
- Table 5-IV 不具有攻角或舵角自变量，因此对应两个字段留空，而不是用 0 代替。

## 原表规则和保留的问题

Table 5-I 原始列次序为 0°、−10°、−15°、−20°、+10°、+15°、+20°。CSV 对每个值显式保存舵角，避免列次序被误当成单调排序。

Table 5-I 的 B-57 末行是 α_H=−12°，B-58 首行直接是 +8°。这是原表节点安排，没有额外抄出 0°、±4° 等数值。后续实现如果在节点之间插值，应标记为插值，不能把生成值重新称为原表数字或实验数据。

Table 5-II 的 M=0～0.2 列写明：使用 Table 5-I 中 δ_e=0°、α_H=−180°～180° 的值。CSV 在各印刷攻角行保留引用；完整适用范围同时记录在 metadata 中。原表要求查表与执行何种插值算法是两件事，本轮不新增算法或外推规则。

未强制正负攻角对称，以下原值原样保留：

- Table 5-I：α_H=−130°、δ_e=+20° 时为 1.54；α_H=+130°、δ_e=−20° 时为 −1.45。
- Table 5-III：M=0.6，α_H=−8° 时为 0.045；α_H=+8° 时为 0.065。

这些差异可在接入模型后继续检查来源或敏感性，但不能由数字化阶段自行修正成对称数据。

## 检查

本轮逐页读取全部数字和续页后，核查了每页行列数、四张表的完整页码、轴键唯一性、数值可读性、缺失值未被填零，以及多个关键源表单元格。特别复核 Table 5-I 的高精度小数、Table 5-II/III 的 Not Defined 边界、上述不对称原值和 Table 5-II 的引用规则。检查没有发现重复轴键；所有非数字记录的 `value` 均为空。

数字化不等于 GTRS 整机模型已经接入，也不等于外部验证通过；本文件仅交付有来源的平尾查表数据和其解释约束。
