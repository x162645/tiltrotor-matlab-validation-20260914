# CR-166536 表格数字化补充：Table 2-II

来源为 Ferguson et al., NASA CR-166536 Appendix B，PDF 渲染页 375、报告页 B-25。Table 2-II 给出旋翼尾迹对平尾的系数 K_Hβ，行变量为 `|β_F|`（deg），列变量为 `β_m`（deg）。本表在身份参数 CSV 中没有独立 field_id，因此采用 `TABLE_2_II_SUPP`，不覆盖 TABLE_001–004 的诱导速度比表。

数值由原始扫描页逐格人工抄录，未插值、拟合或平滑；负号和 0.0 按原表保留。该表应作为平尾尾迹模型的独立查表输入，不能与 Table 2-I 的 `W_i|R/H/W_i` 混用。
