# CR-166536 数字化批次4：Table 4-I

来源为 NASA CR-166536 Appendix B，PDF 渲染页 384–385、报告印刷页 B-34–B-35。表 4-I 是 XV-15 机翼—短舱升力系数 `C_LWP`，襟翼设置 `X_FL1=0/0`，分为 90°（airplane）和 0°（helicopter）桨毂角，列变量为马赫数。

CSV 保留原表的“Not Defined”格子，使用空值并标记 `read_status=NOT_DEFINED`，没有把它们当成零，也没有插值。数值来自原始扫描图逐格读取。该批次仅覆盖表 4-I；表 4-II 至 4-XVI 尚未完成。
