# CR-166536 尾翼常数数字化说明

来源：NASA CR-166536 附录 B 原始扫描页。水平尾翼常数和系数来自 PDF 页 406、印刷页 B-56；垂直尾翼常数和系数来自 PDF 页 419、印刷页 B-69。所有数字均由原图直接读取，未换算、拟合或根据对称性修正。

## 水平尾翼（B-56）

几何字段：`SL_H=560.0 in`、`WL_H=103.0 in`、`S_H=50.25 ft²`、`c_H=3.92 ft`、`i_H=0.0 deg`。系数字段：`tau_e=0.518`、`C_LH_beta=-0.00422 1/deg`、`K_HNU=0.8`、`D_WB=1.0`、`C_MH0=0.0`、`C_MHA=0.0 1/deg`、`D_Ke=0.24`。A-82/PDF150明确给出 C_LH_beta 的单位为 1/deg；其余原表未给出 tau_e、K_HNU、D_WB、C_MH0、D_Ke 的单位，CSV保留 `as_printed_unspecified` 或 dimensionless，不自行补单位。

## 垂直尾翼（B-69）

原表显示 `NVSTAB=2`，两片垂尾的站位/水线/侧向位置分别为：`SL_V1=570.02 in`、`WL_V1=-115.69 in`、`BL_V1=77.0 in`；`SL_V2=570.02 in`、`WL_V2=115.69 in`、`BL_V2=77.0 in`。面积为 `S_V1=S_V2=20.25 ft²`，安装角 `i_V1=i_V2=0.0 deg`。公共几何常数为 `BL_CG=0.0 in`、`SL_SP=300.0 in`、`BL_SP=193.0 in`、`l_m=4.667 ft`、`R=12.5 ft`、`b_W=32.17 ft`。系数为 `tau_r=0.27`、`∂σ/∂p_hat=-0.1`、`∂σ/∂r_hat=0.0`、`K_VNU=1.0`、`a_V=3.02522 1/rad`、`D_Kr=0.24`。原表未对 tau_r、K_VNU、D_Kr 和 sigma 导数给出单位，CSV 保留这种不确定性。

`parameter` 使用 ASCII 形式，便于程序读取；报告原始上下标和公式含义以本文件和原始页为准。这里的“常数”属于 CR-166536 模型输入，不是独立风洞或飞行实测样本；接入整机前仍需核对现有坐标约定和符号。


## 符号、单位和站位冲突复核

- B-69/PDF419 的两个导数符号实际为带帽的 `p_hat`、`r_hat`。A-93/PDF161 分别定义为“滚转速率对垂尾侧滑角的修正系数”和“偏航速率对垂尾侧滑角的修正系数”，单位栏均为 ND。CSV 已将旧 ASCII 名 `d_sigma_d_p`、`d_sigma_d_r` 更正为 `d_sigma_d_p_hat`、`d_sigma_d_r_hat`，并在每行 notes 保存更正依据。
- C_LH_beta=-0.00422 的单位不是未说明：A-82/PDF150 的输入定义明确给出 `1/deg`，CSV 已更正。
- B-69/PDF419 原样读到 `WL_V1=-115.69 in`、`BL_V1=77.0 in`、`WL_V2=+115.69 in`、`BL_V2=77.0 in`。B-12/PDF362 与 A-93/PDF161 分别把 WL 定义为水线、BL 定义为侧线/Butt line。由于 WL_V1/V2 的正负可能存在排印或坐标口径冲突，本项目保留四个原数值；没有依据左右对称性改写。
- 本冲突只影响坐标解释和尾翼力矩臂；在参数接入前需由独立读者复核原图和项目坐标约定。
