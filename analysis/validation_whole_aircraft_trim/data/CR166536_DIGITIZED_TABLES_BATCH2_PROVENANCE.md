# CR-166536 数字化表格批次 2

来源：Ferguson 等，NASA CR-166536 / TR-1195-2 Rev. A，附录 B（XV-15 generic model）。

## 范围

本批次包含原始 PDF 中可清晰读取的表 5-V(a–c)、5-VI、5-VII、8a-I 至 8a-VIII。数据存为长表 CSV：每一行对应一个“行变量–列变量–数值”单元格。`source_pdf_page` 是 PDF 页码，`printed_page` 是报告印刷页码。所有数值均保持报告原值，不做插值或平滑。

## 读取与复核

采用 Poppler 将原始 PDF 以 140 dpi 渲染，再人工逐格读取并复核表头、单位和脚注。`read_status=confirmed_visual` 仅表示该单元格在渲染图中清晰可辨；并不表示它已经接入飞行动力学模型。表 5-V(a–c) 的动压比以 `ratio` 保存，表 5-VI 侧滑损失因子按报告的 ±侧滑角折叠为 `betaF_abs_deg`，表 8a-IV 的两个量分别保存为独立的 `col_key`。

## 重要脚注

- 表 5-V(a)、5-V(b)：速度列为 0、20、40、60、80 和 `>100` kt；尾缘攻角行包含 −180、−40、−30、−28、−24、−20、−16、−12、−8、−4、0、4、8、12、16、20、30、180°。
- 表 5-VI：原报告给出 ±βF，CSV 用绝对值并在备注中保留“±”语义。
- 表 8a-I：脚注为 X_LN=±4.8 in、B1=10.0625°（βm=0）。
- 表 8a-II：速度列为 0–60、80、>100 KCAS，脚注给出 X_PD=±2.5 in 及不同速度的 ΔB1 限幅。
- 表 8a-V：同时保留 present low-rate rigging 与 original high-rate rigging；起停点的括号脚注未编码为数值变化。
- 表 8a-VIII：报告列出 U=0、20、40、60、80、100、400 KCAS，对应增益 0、0、−4、−4、−4、−4、−4。

## 使用边界

该 CSV 是可追溯的数字化输入层，尚未宣称模型验证完成。将表格接入模型前，应再次核对坐标约定、βm 与项目中的 `i_n` 映射、速度单位（kt/KCAS）及表格适用的旋翼/襟翼构型。
