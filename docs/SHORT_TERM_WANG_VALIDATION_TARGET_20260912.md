# 短期目标：达到公开文献结果对比级整机验模强度（修订版，2026-09-13）

## 目标定义

短期目标不是复现王梓旭等人的代码或参数，而是达到其公开论文所展示的验模强度。经本轮目标修订，**公开文献结果对比可以作为有效验模证据**，但必须和试飞数据、模型—模型对比严格分栏：

1. 有明确的具体构型和参数来源；
2. 有可追溯的外部参考来源；
3. 四个短舱角（90°、60°、30°、0°）完成配平趋势的文献曲线对比；
4. 至少三个构型（90°、60°、0°）完成操纵响应的文献曲线/试验曲线对比；
5. 正向和反向过渡仿真作为模型应用结果单独报告；
6. 对公开图表进行数据提取，并报告逐点误差和读图不确定度；
7. 保留不收敛、偏差较大和无法复现的工况；
8. 将验证范围与数据角色分开写明，不把公开曲线称为原始同步飞行时历。

证据分三级：A 为公开试飞/试验点，B 为公开论文图表数字化（必须标注读图不确定度），C 为 GTRS 或 NASA 参考模型输出。B、C 可以支撑“文献结果一致性”判断，但不能写成独立实飞真值。

## 对应公开证据

王梓旭等论文公开页面列出配平结果对比、操纵响应结果对比，以及直升机模式—飞机模式和飞机模式—直升机模式飞行仿真对比；参考文献包括 NASA CR-166536、CR-166537、TM-81177、TM-81244 和 XV-15 频响辨识报告。

## 完成判据（修订后）

只有在同一参数包、同一坐标和输入定义下完成以下项目，才将本目标标为完成：

- 四个短舱角的配平对比覆盖论文中全部可见文献点（90°、0°各 5～6 点，60°、30°各 4 点），不人为补点，并保持同一参数包；
- 三个构型的动态响应有明确输入/输出定义，可复算峰值、响应时间或曲线误差；
- 正向和反向过渡有可复算的输入、状态和输出，但只作为应用/内部对比；
- 每项对比均给出数据来源、数据角色、数字化方法、样本数、误差指标和失败点；
- B 类图表目标均标注 `SECONDARY_FIGURE_DIGITIZATION` 及读图不确定度；
- 结果可由 MATLAB 入口、Python 读回脚本和公开配置重新生成。

当前状态：**文献对比证据已具备，整机多角度运行闭合仍进行中**。图1四角度图示目标、图2三个构型图示目标和 GTRS/NASA 参考输出均已归档；多角度生产运行和图2同构输入复算尚未完成，不能把已有数字化结果误写成原始同步动态验证。

## 与长期通用整机目标的关系

本目标只增加一个公开资料约束的 validation adapter，不把 XV-15 参数或调参结果写回通用核心。通用核心继续保持可换构型；其他公开对象（ERICA、HVAB、TRAST、OARF/WADC）作为部件或整机气动的补充验证路径。完成本目标后，仍需同步全机动态数据才能声明真实整机动态精度或实机飞行品质。
