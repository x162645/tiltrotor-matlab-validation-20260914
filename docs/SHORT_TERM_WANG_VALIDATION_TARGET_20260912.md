# 短期目标：达到公开文献级整机验模强度

## 目标定义

短期目标不是复现王梓旭等人的代码或参数，而是达到其公开论文所展示的验模强度：

1. 有明确的具体构型和参数来源；
2. 有可追溯的外部参考来源；
3. 至少复现配平、操纵响应和正反向过渡仿真三类对比；
4. 对公开图表进行数据提取，并报告逐点误差和读图不确定度；
5. 保留不收敛、偏差较大和无法复现的工况；
6. 将验证范围与数据角色分开写明，不把公开曲线称为原始同步飞行时历。

## 对应公开证据

王梓旭等论文公开页面列出配平结果对比、操纵响应结果对比，以及直升机模式—飞机模式和飞机模式—直升机模式飞行仿真对比；参考文献包括 NASA CR-166536、CR-166537、TM-81177、TM-81244 和 XV-15 频响辨识报告。

## 当前进度与缺口

- Berger13 旋翼动态入流基线仍未正式接入生产整机接口；

- 已形成一套 XV-15-like 直升机模式配平输入并完成 6 个速度点运行（5 个可信收敛，1 个失败点保留）；
- 尚未形成与图2三个构型完全同构的动态输入文件，也未完成图17/18正反向过渡的逐点模型复算；
- 当前外部定量结果主要是 OARF/WADC/Betzina 旋翼部件证据，不能代替整机曲线对比。

## 完成判据

只有在同一参数包、同一坐标和输入定义下完成以下项目，才将本目标标为完成：

- 配平曲线至少覆盖多个短舱角和速度点；
- 正向和反向过渡各有可复算的输入、状态和输出；
- 操纵响应至少包含一个公开的动态响应对比；
- 每项对比均给出数据来源、数字化方法、样本数、误差指标和失败点；
- 结果可由 MATLAB 入口和公开配置重新生成。

当前状态：**进行中**。已跨过“公开图表可复核”的门槛，但不能把图1/图2图示数字化和 GTRS 参考仿真误写成完整的整机外部动态验模；完整目标还需要图2输入同构复算以及图17/18过渡输出的逐点误差。

## 与长期通用整机目标的关系

本目标只增加一个公开资料约束的 validation adapter，不把 XV-15 参数或调参结果写回通用核心。通用核心继续保持可换构型；其他公开对象（ERICA、HVAB、TRAST、OARF/WADC）作为部件或整机气动的补充验证路径。完成本目标后，仍需同步全机动态数据才能声明真实整机动态精度或实机飞行品质。
