# Betzina 2002 低速前飞旋翼初步外部验证结论（2026-09-07）

## 1. 结论身份

本文件冻结当前前飞验证的**阶段性证据**。验证对象是 PR #73 延续下来的低阶前飞旋翼模型，不是 XV-15 整机模型。

当前允许的最高表述是：

> **该低阶旋翼模型已获得低速直升机模式前飞的初步外部验证支持，可以作为后续研究中的可用前飞旋翼模型继续推进；但尚未完成完整前飞包线、转换模式、飞机模式或整机操稳验证。**

本阶段没有根据 Betzina 扭矩残差反调任何气动参数。

## 2. 验证接口一致性

为复现 Betzina 风洞试验的一阶挥舞配平合同，分析层增加了横向周期变距自由度。

零横向周期时，新适配器必须退化回原 Stage-2 前飞旋翼。MATLAB R2021a 一致性门通过，最新代表性审计最大绝对差为：

`2.6112966972666e-17`

全部审计工况物理解算收敛。因此本阶段没有证据表明前飞相关性是由接口改写原旋翼物理造成的。

## 4. Figure 16 扭矩相关性

Betzina Figure 16 公开的是图而不是机器可读原始表，因此试验点身份严格标记为：

`FIGURE_DIGITIZATION_DIAGNOSTIC`

按旋翼轴角汇总：

| 旋翼轴角 | CQ/σ 平均绝对误差 | 阶段评价 |
|---:|---:|---|
| -15° | 6.1375e-05 | 定量相关性非常好，四个点全部落入当前 ±1e-4 数字化带 |
| 0° | 3.1359e-04 | 总体趋势正确，存在随前进速度增加的正扭矩偏差 |
| +15° | 5.5688e-04 | 正确捕捉扭矩快速下降趋势，但在实验扭矩很小时存在系统性正偏差 |

不能用总体百分比误差评价 +15° 高前进速度点，因为实验扭矩已经接近零，百分比会失去意义。

重要修正：这些结果**不支持“前飞模型严重整体失效”**。更准确的解释是：

> 模型能够抓住主要前飞扭矩趋势；预测精度具有明显工况依赖性，其中负旋翼轴角区域表现很好，零和正旋翼轴角区域存在定量偏差。

## 6. 当前内部诊断边界

内部载荷指纹已经推翻了一个简单假设：模型在正轴角高前进速度下并非“不会产生局部负扭矩/载荷反转”。模型内部已经出现明显的正负扭矩抵消。

C81 截面气动表迎角范围有限，超范围查询主要出现在内侧桨段，而不是外侧桨尖。它是需要保留的不确定性，但目前证据不足以把它指定为正轴角扭矩偏差的唯一主因。

因此当前不应为了消除残差直接增加经验扭矩修正，也不应提前宣布非局部尾迹、截面阻力或试验装置效应中的任一项为唯一原因。

## 7. 当前证据支持什么

当前 24 个代表性前飞工况支持：

1. 该低阶旋翼并未在低速前飞中整体失效；
2. 主要扭矩趋势随前进速度、旋翼轴角和推力水平的变化被正确捕捉；
3. 部分区域存在良好的定量相关性，尤其是负旋翼轴角；
4. 零和正旋翼轴角存在系统性正扭矩偏差，属于精度边界，而不是当前证据下的整体不可用；
5. 当前结果足以把模型从“未经外部前飞验证的传播模型”升级为**有初步低速前飞外部验证支持的研究模型**。

## 8. 仍不允许的表述

当前不能声称：

- 已完成 XV-15 全前飞包线验证；
- 已完成转换模式或飞机模式验证；
- 已完成安装旋翼/真实飞行验证；
- 已完成 XV-15 整机配平、稳定性和操纵性验证；
- Betzina 图像数字化点等同美国国家航空航天局原始机器可读数据；
- 当前正轴角残差已经唯一归因于某一种缺失物理。

## 9. 阶段停止规则

考虑研究时间与计算成本，Betzina 当前阶段可暂时视为 **PRELIMINARY PASS**。

近期不需要继续把同一数据库全部数字化，也不需要立即为正轴角残差开发高成本新物理。

下一次扩展前飞验证时，优先级应是：

1. 第二套独立前飞数据的少量代表点；
2. 必要时增加纵向气动力等第二观测量；
3. 再决定是否需要专门的物理增强。

当前主结论：

> **低速直升机模式前飞：初步可用，存在工况相关的精度边界；前飞验证可以暂时冻结，后续再扩展。**
