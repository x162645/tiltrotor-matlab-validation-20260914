## 2. 尾部：不再只接诱导速度

零角速度/侧滑子集中，qH=0.5*rho*KHNU*eta*(U^2+W^2)，不是加入旋翼诱导速度后的模长动压。机翼对尾部下洗用构型表及自由流迎角修正，旋翼对尾部比例保留原符号。原代码带额外0.5的CT不被误用为GTRS合力系数。

## 3. 原旋翼计算中已定位的有限跳变

旧Corrigan修正以alpha>0硬开关，但C81在alpha=0已有正升力。跨零时将修正突然施加在非零CL，产生有限载荷跳变。

真实MATLAB诊断：一叶素由约-5.45e-11deg跨到正侧时，CL约0.07250849跳至0.07862655。扰动逐次减小，只要仍跨开关，原始挥舞力矩残差向量变化仍约12.02745N*m。POLAR_BOUNDARY_RESIDUAL.csv保留整个序列。

V4改为CL_base>0，使增强量在真实零升力边界连续趋零；恢复30-60deg渐退，n=1不变，无自由平滑宽度或目标拟合增益。这是有来源动机的新模型修订，不是原近似alpha=0开关的逐字复现，也不声称所有导数光滑。

来源Koning NASA/CR2016-219086印刷20-21/PDF36-37、式17-20；原文说明正升力条件和近似零升力角。仍保留原翼型迎角截断，未提供缺失的高迎角/反流数据。

V4实际MATLAB26项检查通过，包括有限默认路径身份、14个局部扰动探针。theta75=10/12/14/15deg四个悬停回归点的T/Q与旧值相同；不是OARF/WADC/Betzina全套重验。

修正后四点在原求解器/容差下全部闭合，invalidCount均为0。此前失败不能再被当作不存在物理解的证据；也不推断所有历史失败都有同一个原因。

## 6. 参考数据和证据边界

TableC1的80kt GTRS qdot=-4.89deg/s^2，但总俯仰力矩/惯量不能支持该值；分项/合计也不闭合。原数字保留，不猜测指数，不删除80kt制造通过。见REFERENCE_TABLE_CONFLICTS.md。本报告差异是公开表列参考的描述性相关性，不是无不确定性的真机精度评分。

机身源定义：RevA DLANG=-0.5ft^2；2007表列力解析的面积约为Dalpha+1.0ft^2，差近常数不授权拟合加1.5ft^2。另一子系统起落架舱DPOD=1.15ft^2不能改名替代。机身物理未修改。

参考不一致不是模型免责。操纵量、100kt推力、机翼载荷分配、局部流动及新旋翼的独立回归仍需支持。真实飞行定量、完整转换和动态操稳验证未完成，最终目标未降成仅闭合。

V3/V5当前只支持对称稳态直升机子域；非零角速度、侧滑、转换显式报错。不能删除门限直接算A/B矩阵，再称动态已经验证。
