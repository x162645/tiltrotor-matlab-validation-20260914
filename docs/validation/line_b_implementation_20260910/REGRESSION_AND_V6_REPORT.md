## 1. 本轮关闭的具体问题

新 V4 旋翼不再仅凭旧 M1 标签继承外部验证：实际运行了既有 OARF/WADC 27 点，以及既有 Betzina 24 点的新旧后端回归。27 点悬停、12 点原图前飞、12 点二次转绘前飞是不同等级证据，不能笼统计为51个独立原始试验样本。

工况：OARF Run15/Run14 各6–11deg六点；WADC Run1–3各[6,8,9,10,11]deg五点。读取既有载体，不重新数字化或插入不存在的7deg点。全部54次新旧旋翼调用成功。使用继承的声速340m/s、密度/重力/桨叶质量等合同，这些不是重新确认的试验事实。原总距溯源和设施差异限制仍保留；没有加入经验总距偏置。

V6新增共享gtrs_wing_freefield_angle与可选wing_model_freefield_consistent；尾部只提取既有算术表达式、结果保持。机翼自由流升阻系数与力方向采用修正角，动压仍单独按源自由流定义；本征力矩按整翼面积计算一次、左右各半保存。区域力臂力矩保留。

V5的滑流覆盖、浸没区局部速度与升阻力保持。没有实现完整GTRS尾迹投影、K_FW非均匀修正或独立短舱干扰，不能称完整GTRS机翼复现。此次没有改变旋翼、控制、机身、几何、初值或求解器。

89项实际MATLAB检查通过，包括原尾部对git快照逐值一致、共享角相等、自由流动压与总面积本征力矩、浸没区力与覆盖/局部速度不变、坐标平移和域拒绝。V6同状态条件机翼对比的平均绝对差反而变大：X从74.383到91.028lbf；Z从482.483到585.372lbf；M从532.878到591.777lbf*ft。不能只报告内部一致性或选一项好看的结果。
