# 小步完成：仅改变尾迹覆盖面积是否足够

2026-09-10。基于V6，完成一次固定输入的覆盖面积上限检验；不创建V7物理模型，不更改生产参数，不重跑整机配平。

## 1. 本步的结论

在继承的Table C-1参考状态、旋翼输入和当前V6局部气流/气动系数保持不变时，仅改变机翼被尾迹覆盖的面积，无法复现40/60/80kt表列机翼垂向力。这一点即使将允许面积从现有上限放宽到整个半翼仍成立。

这不是“尾迹问题已被排除”，也不意味着改覆盖面积不能部分改善结果；它排除的是“其余输入全部不变，只改覆盖面积就能消除这些同状态部件差异”这一具体解释。不涉及重新配平后整机结果，不认领实际飞机的误差归因。

## 2. 检验方法

调用既有run_line_b_source_tail_replay获取同一组参考状态和旋翼输入，不新求解旋翼。部件参照复用Kleinhesselink2007 Table C-1 PDF195–198的机翼载荷；其既有分项/合计冲突、输入圆整和来源版本限制全部保留。

令a为每侧被覆盖面积，Sh为半翼参考面积。固定局部气流、系数及力矩参考点时，V6区域气动力与面积成正比：

F(a)=sum_side[(Sh-a)*f_free + a*f_immersed]，0<=a<=Sh。

f_free、f_immersed是当前函数实际计算的单位面积气动力，不拟合或修改。V6本征力矩与a无关，区域力臂力矩按现有参考点计算，因此各载荷分量均为a的仿射函数，区间两端足以给出该分量的上下限。

每侧Sh=8.40772512m²。取a=0、当前值、Sh/2、Sh四个预先规定面积进行直接函数复算，并与区域载荷重组作一致性核查。a=0和a=Sh是放宽的数学边界，不代表真实尾迹必然可以达到它们。没有根据参照反求“最优面积”，没有据此修改SslipMaxHalf。

为验证直接函数与重组一致，仅在分析用参数副本中将既有前向覆盖公式映射到上述规定面积；原P结构逐项不变。没有修改模型源代码、气动系数、来流、控制或生产默认值。

## 4. 这一结果怎样决定下一步

覆盖几何仍值得核实，但不再以“先把面积公式换掉就可能收尾”为前提。下一项限定检查应同时核清单位面积载荷的来源：自由流区与浸没区的有效角、动压、系数参考面积/部件包含范围，以及它们与参考构型的一致性。优先解释40/60/80kt零覆盖端仍有明显不足的现象；不凭此宣布某一项是唯一原因。

这一步只关闭面积单因素充分性问题，不重新派回首次60kt部件对照、V4的27+24点回归，也不启动密集参数扫描。每轮解决一个明确小问题，既有成果继续使用。
