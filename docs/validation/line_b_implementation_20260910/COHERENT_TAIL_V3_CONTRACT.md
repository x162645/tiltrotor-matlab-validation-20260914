# V3实施契约：一致的稳态平尾模型

本文件在V3结果产生前提交。不是重新定义全部项目；继续PR77，V1/V2证据均保留。

## 来源和改变

Ferguson NASA CR166536 Sep1988 RevA。PDF SHA256与上一轮归档一致：a2013a314af5beb0c5e9bc5bbeb26f99be9a8aa63f2ebe07deaaf11d0d44d67d。
已逐页视觉核查A38(106)、A70(138)、A74(142)、A85-A88(153-156)、B33(383)、B49(399)、B56-B58(406-408)、B62-B65(412-415)。括号为1-based PDF页。

V2只追加旋翼速度，但沿用简化翼下洗、有效安装角、局部速度模长动压、线性升力+tanh和原力方向。V3整体改为原文稳态低Mach平尾子模型，不逐个改增益追目标：

- A38/A70/B33：用左右旋翼实际合力范数构造C_RF，分母rho*pi*Omega²*R⁴，不能混用当前含0.5的CT；计算翼自由流迎角修正。仅为下洗查询提供输入，不改变wing_model载荷。
- A74/B49：40/25襟翼/襟副翼构型表及Mach修正；不是旧2CL/(piAR)映射。
- A85：保留已核旋翼局部速度通道；尾部几何安装角0，不叠加旧有效incidence。
- A87/B56/B65：qH=0.5*rho*0.8*eta*(U²+W²)，只在q=beta=0的声明范围使用。eta可大于1，不截成损失率。
- A86/A88/B57-B58/B62-B64：CL由局部迎角/实际舵角二维表得到；CD由含升降舵效应的阻力迎角表得到；力方向也扣除翼下洗。无旧线性舵效重复项，无tanh。
- B56：尾部站位560/103in、面积50.25ft²、弦长3.92ft、几何安装角0。使用同一机体站位基准的既有重心映射，绝对基准跨报告不作额外认领。

只改变平尾及其输入链。原旋翼、翼/机身/垂尾载荷、传动、质量、求解器、容差不改。
仅直升机模式、对称零角速度、M<0.2、alphaF[-30,20]、速度<=140kt、舵角[-20,20]；CL/drag表仅核实[-20,20]角区间，越界明确拒绝，不静默外推。不是完整动态或转换模型。

## 执行

先原默认路径固定输入回归与旧接口测试，再新表节点/维度/来流/动压分离测试。通过后四个已有速度点各一次，统一使用原MAT完整外层/左右挥舞初值。无新扫描、无目标初值、无额外容差或求解升级。失败保留。
V1原始数据、V2每次尝试和V3完整四点分别报告；不按成功子集宣称四点通过。不预设外部准确性PASS。后续小扰动检验不能直接调用此零角速度稳态接口。
原GTRS输出已知且新增模型共享GTRS信息，结果是来源约束参考相关性复评，不是独立盲验或flight validation。

实现测试与数据验收分离。源表某一参考工况自身非平衡或分项不闭合时保留并单列，不将其直接当作精确静态真值。
