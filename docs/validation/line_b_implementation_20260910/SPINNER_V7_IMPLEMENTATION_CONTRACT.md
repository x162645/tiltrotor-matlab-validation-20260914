# V7 原始来源驱动的桨毂罩部件补充

2026-09-10。本文件在V7配平输出产生前固定本次改动，不为结果调参。

原始CR166537的四点完整载荷表将HUB SPINNER单列，加入后ROTOR TOTAL可在打印舍入范围闭合。当前六部件整机未包含该独立项。Kleinhesselink2007第3.1节印刷70/PDF86已明确说明短舱/喷流/桨毂罩使所列少量部件不能直接相加成总量；旧“所有差額都是参考内部冲突”的说法需要纠正。

本步只补两个桨毂罩的合载荷，不补短舱或喷流，也不修改机翼系数/覆盖、V4旋翼、尾翼、机身、控制或几何。CR166536 RevA A75/PDF143给定平均诱导来流；A76/PDF144及B33/PDF383给2*qsp*[1.0+5.5*sin(alphaMast)^3]，面积单位ft²；A232/PDF300给桨毂高度力臂。1.0/5.5是源spinner参数，不是拟合机身/机翼阻力系数。

实现model/gtrs_spinner_steady.m，显式P.aeroExtras.spinnerModel启用后作为第七个独立部件加入stage2总载荷；原参数不存在该字段，默认仍保持六部件原行为。用当前低阶hub/CG位置，不从目标力矩反求力臂。源条件回放因此可能力更接近、力矩仍带既有几何近似差异。

先检查原始四点的条件部件预测、双罩计数、SI/英制独立公式、阻力方向、零诱导极限、对称性、坐标平移、越界以及关闭新接口时的原总载荷逐值一致。只有实现检查完成后，按原四点各复算一次；使用原求解器、初值及0.005门限，不自动晋升或合并。大致计算规模与V6相同，数分钟，不开展密集扫描。

新原始输入载体用于部件回放；整机V6/V7比较仍使用相同的原论文四点标量参照，避免把参考版本更新和物理变化混在一起。源共享相关性不是独立飞行验证。原整体绝对误差不因补一个部件而预先认领已消除。
