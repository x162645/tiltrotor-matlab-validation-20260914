# Drones 2022, 6, 92：XV-15中间短舱状态验证核查

## 结论

文章提到了并计算了 XV-15 的中间短舱状态，但没有对这些中间状态给出同等强度的独立外部验证。

## 文章实际做了什么

- 建立了包含旋翼、机翼、机身、平尾、垂尾和六自由度方程的 Simulink 模型。
- 将重心和惯量写成短舱角的函数。
- 明确计算了短舱倾角 15° 和 75° 的过渡状态配平，见 Figure 6。
- 这些 15°/75°曲线是作者模型自己的配平输出，用来说明控制趋势，不是外部试验对照。
- Figure 7 将“数学模型、GTRS、XV-15”进行比较，但图中速度约60–150 m/s，比较的是飞行模式的俯仰、纵向杆位和升降舵；文章没有把该图明确标成15°或75°的中间短舱角验证。
- 文章文字还明确说 XV-15 数据不足，因此模型和实际结果会存在差异。

## 验证强度判断

| 状态 | 文章是否计算 | 是否有独立外部点 | 能否称中间状态外部验证 |
|---|---:|---:|---:|
| 90°直升机模式 | 是 | Figure 7主要不是该状态；Figure 5为模型结果 | 不能据此确认 |
| 75°中间状态 | 是，Figure 6(b) | 未给出同状态试验点 | 不能 |
| 15°中间状态 | 是，Figure 6(a) | 未给出同状态试验点 | 不能 |
| 0°飞行模式 | 是 | Figure 7有XV-15/GTRS/模型曲线 | 可以称有限的稳态外部比较 |

## 对本项目的启发

这篇文章可以证明“中间短舱角配平研究是合理且常见的”，但不能作为15°/75°外部验证数据源。它的15°/75°结果只能作为模型趋势和方程实现的文献对照，不能反向当作实验数据。

本项目仍应使用 Yan 2023 Figure 8 的90°/60°/30°/0°飞行试验标记做四角度外部配平比较，并明确其是公开图表数字化目标；Drones 2022 的15°/75°结果另列为“文献模型内部结果”，不混入外部误差统计。
