# V7 功率偏低的误差核查结论

## 已排除的原因

固定 40、65、85、100 kt 的已接受配平状态，重新用相同状态和相同控制量调用整机方程，不做新的配平搜索。重放与原记录的最大气动力差为 `4.89e-9 N`，最大俯仰力矩差为 `7.77e-12 N·m`。左右旋翼推力、扭矩、诱导速度和攻角裁剪计数逐点一致。因此这次差异不是求解器切换、控制映射漂移或缓存错误。

功率逐点按

`P = Q_left Ω + Q_right Ω`

计算，左右旋翼相等，589 rpm 的角速度只使用一次。没有单双旋翼因子遗漏；当前输出也没有发动机、传动和附件损失。部件力矩相加与整机气动力矩完全一致。

## 找到的主要问题

功率偏低主要应归入**旋翼扭矩/功率预测不足**，而不是整机力矩平衡或功率汇总错误。原因有两层证据：

1. 当前 V7 的功率完全由旋翼扭矩决定；固定输入重放证明该扭矩是当前模型的稳定输出。
2. 项目已有独立 OARF/WADC 旋翼外部审计显示，冻结 M1 在 WADC 上的 CP MAPE 仍为 `51.11%`，平均有符号误差为负；CT MAPE 为 `37.90%`。这说明当前 M1 旋翼在外部数据上仍有系统性载荷和功率低估，能够解释整机图中的功率偏低。

高速端攻角表裁剪次数从 80–85 kt 开始增加，105 kt 达到 20 次。它是一个需要继续验证的候选机制，但目前不能单凭相关性认定它就是低功率的唯一原因。

非旋翼俯仰力矩会随速度变化并影响杆位：100 kt 时机身负俯仰力矩约 `-10784 N·m`，平尾/垂尾合计约 `9203 N·m`。这能解释杆位斜率变化，但不直接解释旋翼轴功率偏低。

## 下一项有判别力的试验

保持当前基线不动，做同输入的旋翼外部量对照：逐点输出 `CT、CP、FM、Q、Hlong、Hlat、inducedVelocity、alphaClampCount`，先在合法 C81/攻角范围内比较“原始截断”和“合法外推/无截断”两种明确模型分支。若 CP 改善而 CT/FM 不恶化，才允许进入来源审查后的修正；否则保留当前 M1 并把功率低估写成适用域限制。

这一步之前不应通过调整总距、转速或功率比例去追论文曲线，也不应把当前功率结果用于确认发动机余量或过渡走廊边界。
