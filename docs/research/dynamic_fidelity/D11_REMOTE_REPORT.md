# D11 远端摘要：参数资格、分别约束与共同升沉通道

本页根据本对话完整 D11 报告、台账、代码及结果读回整理，是后续上传的摘要，不是原始完整报告的逐字镜像。原始完整附件及本次远端覆盖范围见 D06_D11_REMOTE_ARCHIVE_SCOPE.md。D11 新增数值均为本地 Python；没有把它改记为 MATLAB 或新的实机验证。

## 1. 已作出的数据取舍

固定 CF k=.637*4/3、PP k=128/(75*pi)，仅释放 CT=alpha*theta-b*q/Omega 中的 alpha>0、b>=0。使用 TN3044 的完整 6deg/s 慢速瞬态 21 个非零初始观测训练，不使用快速曲线目标拟合，不新增偏置、延迟或状态。

CF 最小二乘 alpha=.03142901837、b=.03999323383，慢速 NRMSE7.5634%；局部极小极大最大残差/原读图半宽为2.889868。PP 和 QS 分别约3.245712、3.245798，均未达到<=1的原读图盒资格。八个显式输入情景也未找到合格结果。这是已执行搜索未获资格，不是全局不可行证明；读图半宽不是完整试验置信区间。

PP 最小二乘把 b 压到近零，意味着入流状态对推力输出近乎不可观测，不是实验证明记忆不存在。冻结慢速拟合后，CF 在20/48deg/s开发性曲线上 NRMSE5.7146%/11.6618%，PP为10.0911%/12.3782%。全部旧 TN3044 曲线已用于开发，不能重新标为盲测。

慢速共同观测误差比较集合中的 CF 参数，在20deg/s给出4.7471%-17.8625%、48deg/s给出10.0106%-29.0673%的预测NRMSE范围。这是诊断集合，不是相容参数置信区间；参数非唯一会影响目标预测。因此不发布当前模型类的已获资格绝对推力参数。旧source_unadjusted、D09_nu、D10_effective_load_gain及不利结果保留在原完整附件。

## 2. 静态与动态证据进入不同位置

静态表 S(theta)来自固定D05提交的 analysis/run_m1_stage3_corrigan_stall_delay.m 中 OARF Run15 六个6-11deg点；Git blob 8ef7b1897c56e0c54d9475b4069cc0982d7c3b15。R=3.81m、3片桨；输入 theta75_report_index_rad 是0.75R报告坐标，不是已测旋转受载总距。小范围尖速差异并置、恒等有效输入映射均为显式假设，不允许表外推。

非平衡流入导数 b=Nb/(2*pi)*integral[a(x)*c(x)/R*x dx]，来自独立参考C81小攻角割线与径向弦长。C81来源 analysis/build_xv15_c81_low_order_section_aero.m，Git blob d1bbcc351d2afa7eaebdeeaba4afec95ac52b264，NASA/TP-2004-212262附录A参考模型紧凑表，不是原翼型风洞真值或OARF目标反求。中心/左右割线及不延用未知根段给出 b=.15160528305/.14613997471/.15707059139/.14642463511；这些不是置信界。

CT=S(theta)+b*[sqrt(S(theta)/2)-(vi+v_up)/Vtip]。

所有稳态点对任意b都回到S；因此六点完全重合是构造性质，不是新增验证，静态曲线也不能识别b。TN3044拟合参数没有被移植为XV15参数。

## 3. 已计算的通道

vi_dot=Vtip*Omega/k*[CT-2*vi*(vi+v_up)/Vtip^2]；v_up_dot=2*rho*pi*R^2*Vtip^2*CT/m-g。

概念质量6000kg继承D07；rho1.225、g9.80665为显式设定，Vtip=768ft/s。静态表直接解得 theta0=6.4579994584deg、CT0=.009610669711、vi0=16.226991585m/s。PP极点约-48.95521、-.211666；CF约-31.47561、-.210570。

这是对称共同输入、短舱直立的两状态概念双旋翼模型。没有自由姿态、翼尾干扰、机翼下载、挥舞惯性载荷或执行机构；气动推力作为桨毂载荷近似。不是原生产九状态或D05七状态的直接降阶，不是已验证XV15。

0.1deg和0.05deg光滑脉冲已实际运行。PP非线性/局部线性NRMSE，速度约.2154%/.1080%，加速度约.2845%/.1427%；这是实现一致性，不是试飞误差。

## 4. 成熟方法及力学约束

同一源模型、输入、输出和网格比较FULL2、物理QS1、多输出BT1/BSPA1与速度BT加运动学重构。严格力学接口为D_v=0、C_a=C_v*A、D_a=C_v*B。原始BT/BSPA不自动保持a=dv/dt，其数学近似保留，但不直接替代物理升沉状态。速度专用BT是明确改变投影目标的经典合规对手，不包装为新气动方法。

两种k和四种b构成八个有限参考解释，不覆盖全部真实误差。在0.1-3rad/s，名义PP2相对该族的最大复数差2.1797%，QS1为5.6060%，合规速度BT1为5.5717%。在3-10rad/s，PP2也达到5.9192%。因此本局部工作点的0.1-3rad/s默认保留经典两状态；高频输出条件族，不发布同一5%预算的单模型资格。5%是预声明模型间演示预算，不是航空标准；有限网格不是连续严格界。

8001采样、相同Python精确FOH推进，二状态中位44.80ms、QS42.93ms、合规BT42.67ms；含解释器和expm设置，未证明显著加速或MATLAB实时性能。
