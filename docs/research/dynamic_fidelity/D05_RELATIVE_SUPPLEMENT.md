# D05 补充：绝对增益误差与实际响应相对误差分开

2026-09-11。首轮34601330893/309d01d已结束，388检查通过，结果保持不改。补充不是修物理或移动原门槛，而是防止误读5%固定增益尺度。

原规则的预算是0.05*gScale，gScale为名义直接总距载荷导数，不是每个响应的幅值。因此某个很弱的通道，即使绝对增益误差很小，其相对于实际响应的误差仍可能很大。首轮数据中PP、epsilonA=.1、差动输入、10-30rad/s升沉的固定尺度误差约1.65%，实际响应相对差约18.1%。原绝对规则数学上没有矛盾，但不能写成“动态相对精度5%以内”。

新增规则仅调用原Ared/Bred/Cred/Dred和分块误差界，不计算完整7状态FRF作选择。对区间上界b和降阶响应幅值下界gmin：若gmin>b，则原7状态响应幅值至少为gmin-b，从而相对误差<=b/(gmin-b)。gmin由中心降阶FRF与resolvent变化界得到；下界不足或接近零时不授予相对误差资格。

本补充仍采用5%相对预算作为演示，而非航空操稳标准；分别保留绝对和相对两列决定，不能删除原不利结果。相对规则也是充分条件，拒绝不代表必然超差。数学推导为局部LTI、零初始增量和指定输入方向/频段；双精度实现不是外向舍入区间机器证明，更不是有限幅值全时域峰值保证。
