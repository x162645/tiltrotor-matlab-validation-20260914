# 《航空学报》投稿资格判断（D17）

判断日期：2026-09-12。

## 结论

**可以形成方法与部件级外部证据的完整候选稿并进入投稿评估；不能在当前证据下声明全机动态精度或国内领先。**

全机同步数据缺失只阻断以下主张：XV-15 实机动态精度、执行器到受载总距的全链路准确性、载荷到机体升沉的实机预测、全包线能力和国内领先排名。它不阻断已有部件数据支持的模型改进、外部比较、失败机制分析和面向操稳/控制的条件性方法研究。

## 已具备的投稿支撑

1. **问题重要且边界明确**：面向倾转旋翼操稳与控制的低成本动态预测，明确区分静态映射、诱导流记忆、升沉接口和外部真实性。
2. **方法比较不是单一自家模型**：直接非线性源、21×41 查表、固定工作点线性化、总距调度解析传播和准定常负对照在同一输入、时间网格和评价规则下运行。查表最大误差 0.1114%，调度传播最大误差 0.2707%；固定线性化最坏 168%，准定常 100%。
3. **有工程接口**：载荷接入条件升沉方程，并报告速度/加速度一致性和在线成本，结论明确限定为条件性仿真收益。
4. **有独立部件级外部来源和可追溯负结果**：Woodgate/NUAA 公开接受稿提供独立旋翼 collective-pitch 到 `C_T` 的动态实验图示。当前复现发现附录代码时间原点、静态 `C_T` 量级与图示实验尚未闭合，因此撤销此前“动态入流略优于准稳态”的定量表述，将其作为失败复现和后续模型改进目标；同时保留读图误差、原始数组缺失和构型不匹配边界。
5. **证据可复核**：MATLAB R2021a 主结果、Python 独立读回、外部来源哈希、逐点 CSV、运行 manifest、失败初版和中文候选稿均已保存。

## 投稿前仍应补强的内容

- 将论文主张明确写成“条件化低成本预测方法 + 通用旋翼部件外部证据”，题目、摘要和结论避免暗示已完成 XV-15 全机动态验证。
- 将 Woodgate 检查扩展为更强的同源方法对照：至少并列准稳态、附录等价动态入流和带挥舞状态的方程实现，并说明图点数字化的误差尺度。
- 先解决 Woodgate 附录的时间原点、静态归一化和参数角色，再恢复任何定量 RMSE；在问题闭合前，不把图点数字化结果写成外部验证。
- 补充一张“任务—证据—结论”矩阵，区分部件检验、系统接口检查、条件性控制演示和实机验证。
- 对国内对标只比较任务、输入层级、输出、外部验证和成本披露均可匹配的部分；没有同任务证据时，不写速度或精度排名。
- 投稿后若取得同步系统记录，再单独升级为全机动态资格，不回写当前部件检查的数据角色。
