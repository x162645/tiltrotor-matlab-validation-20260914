# D13 计算前约定：工作点载荷增量与低成本实现

2026-09-11。父版本5979d35cd6b22b1f8304210cf378f1241bbdfadb。用户要求回顾国内领先主线并继续实施。本包不增加物理状态，不重新读取TN3044曲线，不拟合TM89428输出。

## 主线与本步位置
长期是外部证据约束下的低成本倾转旋翼动态预测，服务操稳/控制。短期需要一个具体、可比较、可反驳的《航空学报》贡献；状态数、检查数、移植语言不是创新。D11/D12关闭了部分参数用途和输入歧义问题，未建立真实动态精度/成本优势。本步改进尚薄弱的非平衡载荷通道，并真正测量同任务误差和成本；不把本步单独称国内领先。

D11用C81零迎角附近割线形成常数b。新候选保持原静态表S(theta)、质量6000kg、R3.81m、Vtip768ft/s、rho1.225、g9.80665和两状态平均入流/升沉。以原始金属桨非线性扭转、径向弦长和四段C81，按实际局部迎角、局部Mach求B(theta,lambda)。声速340m/s、零锥度、均匀轴向来流、刚性桨、根段延用第一翼型为显式假设；不启用Corrigan参数、不安装反算输入链。源模型C81输入不是原始翼型测量或新的动态试验。

令lambda_s=sqrt(S/2)，e=(vi+v_up)/Vtip-lambda_s。新载荷CT=S+B(theta,lambda_s+e)-B(theta,lambda_s)。这继承D11的静态锚定约定，只把线性增量换成源气动增量。S处恒等不是验证；原始B与S的差必须输出。绝对载荷、力矩、功率和实际受载桨距仍未获得独立验证。

## 冻结比较
直接径向C81积分作为同方程数值参照；对手为经典二维线性查表(21x41和41x81)；工作点导数随theta调度的一阶增量、原D11常数b均保留。所有同一环境、同一外部输入、同一两状态、同一RK4步长与观测。二维表可胜出并作为条件默认，不将查表或泰勒展开称原创。

表域theta报告坐标6至11deg，e为[-.01,.01]；两表均包含e=0并严格保持静态增量为零。超域拒绝，禁止裁剪或外推。表网格和101个非节点确定性验证查询在计算前固定，不用外部输出选择表格。原C81窗口和Mach范围外拒绝，继承helper的clamp计数必须为零。

径向分段中点积分在根切.0875、.2、.25、.55、.8、.95、1处分段，64/128/256点每段，仅评估本次源导数的数值依赖。导数步长1e-4/5e-5/1e-5；主参照为256点每段、h1e-5，分辨率差另报。根段不延用(.2R截起)作为有名称的解释分支，不能改全盘面积或机械半径。

动态：PP平均入流，0.1deg与0.3deg报告坐标共同光滑脉冲，t0至4s、dt.005；0.3deg直接积分dt.0025作新增定向积分检查。观测向上速度、加速度和总气动推力；力学恒等式核对。保留所有方法，不按误差删候选。方法演示预算为两个输出NRMSE均<=1%，不是实机标准；计算通过不自动给连续全域保证。负结果同样交付。

成本：同一MATLAB执行中100个固定载荷查询、五次计时、中位数；离线建表成本单列。动态各方法也记录实际计算时间，但单次动态时间不称稳健测速。不得把kernel加速称完整六自由度或实时平台加速。

外部仅沿用D12已见识别描述的固定0.1至3rad/s形状诊断，原物理与新导数均报告；不是新盲测、不是已匹配的飞行试验。先形成源导数，再计算对外部形状的影响，禁止反调导数追0.105极点。不能以内部查表误差替代外部真实性。
