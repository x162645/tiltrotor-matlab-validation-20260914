# D05：面向输入/输出的近对称动态状态保留

## 目标与有界范围

D04的7→4只在严格共同运动下精确。本步研究：有明确两侧气动差异或差动操纵时，能否保留共同入流和锥度动力学，代数消去差动状态，并依据输出误差判断是否允许这样做。问题不是继续减少状态数，而是建立“输入/输出/频段/误差预算→保留阶数”的可计算规则。

继承D04 TN3044 Eq2-5/11-20、TM88327 Eq9/Table1的轴向载荷和机械质量矩阵。两侧liftSlope=a*(1±epsilonA)，其余几何、Ib、S、Omega和总质量相同。epsilonA是明确的假设数值对照，不是实测公差。对照模型使用相同参数、实际输入和解析工作点，不拟合响应。

经典出处：静态残差化/匹配DC增益的分块消元不是新方法。公式可与MathWorks官方modred的Algorithms核对：https://www.mathworks.com/help/control/ref/statespacemodel.modred.html 。本实现不依赖该工具箱，也不使用新版本专用API。输入输出贡献驱动的模态选择亦有长期先例，例如Skelton/Hughes1979，NTRS19800047526。需要后续文献差异核查才能论证原创性。

## 非线性4状态模型

保留x=[mean(vi),mean(beta),mean(betaRate),w]。差动状态为d=[halfDiff(vi),halfDiff(beta),halfDiff(betaRate)]。
令其导数f_d=0，得到rateDifference=0；由相同转子机械参数，betaDifference=(Q_L-Q_R)/(2*Ib*Omega²)。等几何与相同表观空气质量下，入流差动方程对viDifference为线性，可直接求解（实现axial_residualized_rhs）。

完整7状态和降阶4状态均是实际非线性ODE。4状态直接计算2×2机械系统，没有暗中积分7状态，也没有任意时间常数。它不代表被消去的差动状态真实没有动态；该误差必须评价。对称共同输入为已有精确结果的特例。非对称/差动情形不预设等价。

## 局部线性化与误差表达式

在同一解析工作点，按物理共模/差模变换并以固定几何速度尺度无量纲化：

xDot=Acc*x+Acd*d+Bc*u；dDot=Adc*x+Add*d+Bd*u；y=Cc*x+Cd*d+D*u。

残差化模型A0=Acc-Acd*Add^{-1}*Adc，B0=Bc-Acd*Add^{-1}*Bd，C0=Cc-Cd*Add^{-1}*Adc，D0=D-Cd*Add^{-1}*Bd。线性化由同一非线性RHS推导，另外数值差分核查，不另造响应公式。

对s=j*w：R0=(sI-A0)^{-1}，Rd=(sI-Add)^{-1}，Delta=Rd+Add^{-1}；给定实际输入方向e，H=R0*B0*e，F=Adc*H+Bd*e，K=R0*Acd*Delta*Adc，q=R0*Acd*Delta*F。

精确分块消元给出：
E(s)=[C0+Cd*Delta*Adc]*(I-K)^{-1}*q+Cd*Delta*F。

这是7状态线性模型与4状态线性模型的复数传递差。若||K||_2<1，则第j输出满足
|E_j| <= ||Ceff_j||_2*||q||_2/(1-||K||_2)+|Cd_j*Delta*F|。

选择器不需要计算7状态的频响来决定保留阶数；完整频响仅用于独立验证界的实现。全模型A仍需建模和局部线性化，不能声称没有离线全模型成本。

## 连续频段的充分界

区间中心wc、半宽h。对任一R(w)=(jwI-A)^{-1}，若h*||R(wc)||<1，则
||R(w)-R(wc)|| <= h*||R(wc)||²/(1-h*||R(wc)||)。

将该界分别用于R0和Rd，按乘积/三角不等式界定K、q、Ceff与直接输出余项，得到区间上界。代码逐项记录。界太松时细分区间，不改变误差预算。中心充分界已超预算或达到限定深度时标为NOT_CERTIFIED，并保留全7状态；这不等于已经证明4状态不准确。

数学界覆盖连续区间（在精确算术和局部LTI假设下），程序为双精度计算，非带外向舍入的区间算术机器证明。误差是相对于当前理论模型，不是现实误差；加速度和差动载荷分开，不能凭一种输出通过替另一种输出担保。频域界也不是有限幅值、非带限输入的全时域峰值界。

## 固定本轮比较规则

两种入流系数族PP/CF；epsilonA=[0,.02,.1,.2]；共同、混合[1,.9/1.1]、差动[1,-1]三种实际总距方向；频段[.3,3]、[3,10]、[10,30]rad/s；输出为向上加速度和右减左桨毂传递力。
输出尺度固定为名义直接总距载荷导数：2*Ttheta/m及2*Ttheta，单位分别m/s²/rad、N/rad。5%只是方法演示预算，不是操稳标准、实验误差限或录用门槛。开发过程中用Python方程预检，不称本轮参数扫描为盲测；MATLAB执行之前冻结此规则。没有因结果改变真实模型参数。

由交换对称性，围绕epsilonA=0，共同输入→共同输出的线性约化误差首个非零项为O(epsilonA²)；差动输入或差动输出一般存在O(epsilonA)泄漏。这个结论有前提（光滑、等机械参数、对应工作点、线性化），不能扩展到任意非线性阶跃；代码用小参数比值作验证而非拟合判据。

四种不用于修改公式的非线性检查：epsilonA=0的差动输入、.07的共同输入、.15的混合与差动输入；实际输入为平滑启振正弦2或12rad/s，±0.2/0.1deg幅值，不使用任意执行机构延迟。不是新的试验留出集。尤其epsilonA=0、差动输入时，线性升沉通道为零，但非线性仍可出现二阶响应，必须保留该反例。
