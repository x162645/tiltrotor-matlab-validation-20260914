来源基线是 services/run_d02_longitudinal_heave.m、model/rotor_model_bemt.m、model/total_forces_moments.m、model/tiltrotor_eom.m 的 21a699a 版本，以及该版本的名义参数和原测试。当前模型计算与实现检查均已在 GitHub Actions 中执行，没有使用 D01 的已识别传递函数作为飞机模型。

- 把实际入流状态与动量映射目标分别输出；静态动量闭合与动态载荷求值有效性分别记录。旧 static physicalConverged 字段保持原含义，动态消费者改用新的明确状态。
- 建立统一 RHS、状态/输入/输出合同，15状态动态版与13状态准定常版共享气动函数和执行机构。后者代数求解入流，不以tau=0或虚设状态代替。
- 由现有机体系方程推导观测输出，区分机体系速度导数、惯性垂向加速度、机体系比力和向上高度率。A/B/C/D均由同一RHS和输出函数得到。
- 阶跃事件按实际时间切分ODE积分，输出采样不决定命令发生时刻。工作点显式保存并在各轨迹间复用。
- 动态旋翼内只复用同一次调用中刚计算过的相同叶素载荷，不使用跨调用缓存或上次调用初值。对旧代码的三组状态、静态/动态两种入口，共六组F/M/xdot回归逐值一致。
- 记录ODE、旋翼、挥舞、输出回放各层的调用数和耗时。源代码、参数副本、原始MAT、CSV和日志全部保留。

模型参数、旋翼气动/挥舞公式、质量、几何、控制传动及假设tau_i=0.15s、tau_a=0.08s未改变。动态规律仍是目标映射松弛，不是Pitt–Peters模型，也不是新辨识的物理时间常数。

## 2. 首轮失败与原因处理

首轮 run34580750797，计算13ca086，artifact10191624893；十条轨迹都完成，65项检查中唯一失败是严格工作点检查。

原零速配平只调整总距，固定姿态和周期变距，保留uDot=-9.192352848e-5m/s²、qDot=1.378852927e-5rad/s²。单纯加严旋翼内迭代使入流导数残差降到6.41e-8，但不能消除这两个未参加单变量平衡的分量。CHECKS首行的value只打印入流残差；失败原因由原MAT的完整导数确认，不能只按那个单值判定。

修订使用相同Nelder–Mead/fminsearch算法，在原配平附近对theta、collective、cyclic三个变量求X/Z/My平衡。没有输入外部目标，没有减去f0，没有调整物理参数或放宽门槛。原production trim、细化初值、最终变量和调用次数均保留。

细化只需纵向周期约+0.001044903deg；总距变化约7.13e-11rad，姿态变化约-4.20e-14rad。细化242次目标调用。新的动态工作点九个机体导数最大绝对数值为3.6268e-11，入流导数残差6.4117e-8m/s²；各导数量纲不同，前者只作实现记录，不构造混合物理精度指标。

原服务门限body<1e-3、inflow<0.005保留；本次测试的额外严格门限均为1e-5，没有事后放宽。执行P副本收紧inducedTol到1e-9、flapResidualTol到1e-10、允许60次原入流迭代；默认params_nominal数值未改。这些是明确的数值精度设置，不是物理修订。

## 4. 动态与准定常差异——不是对真实飞机的误差

0.2deg总距输入下，两者向下加速度增量的RMS差约0.004755m/s²、峰值差约0.020386m/s²；单旋翼推力峰值差约57.118N；左入流峰值差约0.043201m/s。

同幅值周期输入下，q增量的两模型峰值差约3.42e-9rad/s，当前均匀平均入流松弛对这一工况的直接俯仰通道几乎没有影响。这只属于当前假设模型和工作点，不支持真实倾转旋翼入流动态与俯仰无关。

固定其他状态时，线性化入流子方程的局部自项约-18.2438/s，对应约0.054813s的自恢复尺度，而非设置值0.15s。原因是目标映射本身依赖当前vi；该数值由本次A矩阵计算，不是新的试验辨识参数，也不是全机模态时间常数。

## 5. 必须保留的限制

两档单边导数检查显示，wDot对u/v的左右导数差仍约0.00592/s，缩小步长后没有趋于一致。它与现有零速模长/覆盖表达的潜在非光滑性相符，但本轮没有做独立部件归因，不将某部件认定为唯一原因。

周期→升沉等很小的交叉响应不能获得与主通道相同的线性资格：例如0.2deg周期下向下加速度增量RMS仅约6.7e-5m/s²，其线性误差可与信号同量级。不能用主通道NRMSE小，就声称整个A矩阵或全部耦合通道都可靠；也不应单看近零信号的百分比夸大其绝对影响。

本轮只有一个悬停点、正向小扰动和短时间窗口。没有开展原始飞行数据比较、完整频带验证、转换模式、大机动或负推力状态验证。D01的外部通道资格缺口仍在。后续应保留假设松弛基线，以有来源的动态入流关系及明确有效工况开展物理对照，不能调当前时间常数追曲线。

## 6. 成本记录

同一第二轮运行中：动态五条轨迹ODE耗时合计12.9419s、2224次RHS、4448次挥舞求解；准定常五条为84.7629s、2194次RHS、78792次挥舞求解。诊断回放另耗时1.9660s与11.8121s；工作点生成及细化11.0234s。完整套件记录128.0323s，不包含安装和Actions启动。

准定常路径每次RHS需要反复求入流/挥舞平衡，当前动态路径只解一次给定入流下的挥舞，这解释了此实现的成本差异。两种方程的动态预测本来不同，因此不能把该倍数当成同等外部精度的速度优势，更不能据此宣称实时保证或国内领先。第一轮与第二轮宿主速度差也不作为算法改进收益。
