## 可证伪命题

## 来源与模型合同

静态 S(theta_report) 复用 D11 六点 OARF Run15 PCHIP，已全部用于开发。几何/C81复用当前仓库原实现；主源为现有 V4 连续正升力修正，OFF 为机制消融，旧 discontinuous N1 仅保留局部导数诊断。V4既有27点静态回归不自动识别非平衡增量。NASA TM86833 PDF8/印刷6页给报告坐标来自执行器位置、误差估计<±1deg；不是动态执行器时历，也不保证局部映射导数。

主域 report theta=6..11deg，lambda departure e=±0.01，不外推；R=3.81m，Vtip=768ft/s，声速340m/s，三桨叶，刚性/轴向均匀/固定桨毂，无翼下载和机体运动。根部延用与原D13相同。CT归一化为rho*pi*R²*Vtip²；lambda=vi/Vtip；k_PP=128/(75*pi)，k_CF=0.637*4/3。两者是分别命名的经典/旧经验条件，无新参数辨识。

CT=S(theta)+B(theta,lambda)-B(theta,sqrt(S(theta)/2)); dot(lambda)=Omega/k*(CT-2lambda²)。负CT、非有限值、查表域外和C81夹取均拒绝，不通过静态相消掩盖B-S原残差。
