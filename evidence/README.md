# Reproducible evidence package

This directory contains compact, executed evidence from MATLAB R2021a runs on 2026-09-12. CSV files preserve point-level outputs and metadata. Run 15 and Run 14 are NASA OARF-derived component checks; WADC is a cross-facility component comparison. These are external component checks, not synchronized XV-15 full-aircraft dynamic validation. The full report is in `docs/EXTERNAL_VALIDATION_REAL_RUN_20260912.md`.
